# data/

- `synthetic/` — сгенерированные тестовые территории (`python -m scripts.generate_synthetic_data`), не коммитятся (см. `.gitignore`), нужны только локально для прогона пайплайна до открытия реальных данных 15.09.2026.
- `samples/` — сюда кладём примеры реальных геоданных, когда они появятся: DXF-чертежи с коммуникациями от организаторов/Мосгеотреста, открытые слои data.mos.ru (зонирование, реестр зелёных насаждений).

## Открытые источники, которые можно смотреть уже сейчас (до 15.09)

- data.mos.ru — открытые геослои Москвы (улицы, здания, зонирование, реестр зелёных насаждений). Проверить, какие слои реально доступны через API, и оценить их формат/атрибутику для маппинга на `object_type`/`zone_type` в `geo_engine`.
- Публичные учебные/демонстрационные DXF-чертежи инженерных сетей — для обкатки `geo_engine/io/dxf_reader.py` до появления реальных примеров от организаторов.
